This video is a continuation of previous video PE #124. It shows how to derive the analytical averaged model of the CCM SEPIC converter from the analytical model developed in previous video. The analytical averaged model is used to model the behavior of the averaged variables of the converter. The model can also be implemented in SPICE-based simulators to perform both time and frequency simulations. The video shows how to implement the model in Qspice and how to obtain the frequency response of the control transfer function from the analytical averaged model.
